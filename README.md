# Insane 2026 Clashfinder — historical artifact

This repository preserves the completed Insane Festival 2026 timetable/clashfinder and its schedule/style audit evidence.

The event is over. This repository is **historical**, not an active homelab application or ongoing schedule service.

## Preserved artifacts

- `index.html` — final static clashfinder surface;
- `schedule_audit_*.csv` — schedule comparison/audit outputs;
- `style_changelog_*.csv` and style JSON files — style classification evidence.

Do not treat these files as current external festival data. Preserve provenance and audit outputs rather than regenerating them casually.

No active runtime, deployment, task backlog or Golden current-state tracking is required. If a future festival project reuses this work, create/promote a new active project rather than turning this historical repository back into a mutable current-state source by accident.
